# Project rules
- Keep portfolio identity, skills, and project records in a shared typed data module so every section uses consistent resume-backed content.
- Keep the app a static, anchor-navigated React/Vite page and preserve the GitHub Pages artifact workflow and CNAME so deployment needs no server runtime.
- Use global semantic color tokens and the shared Button component for controls so styling and accessibility remain consistent.
- Use Radix Dialog for project details and a reduced-motion-aware reveal wrapper so overlays and animations are accessible.
